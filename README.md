## Brief

Context
I am writing a book about game design titled Playing the Variation Game which involves
proposing a way to learn game design by creating variations on simple pre-existing games
(e.g. Go Fish or Pong). I’ve made many of these games over time (e.g. PONGS and
SNAKISMS). I’m interested in the idea of some “edutainment” software that would allow a
user with no technical experience to create variations of a specific underlying game
through a simple user interface.
Design Problem
How can we create an interface that allows editing and playing of a simple pre-existing
game (e.g. Pong). The editing should allow a suJicient breadth of expressive possibilities
that users can come up with genuinely diverse outcomes (e.g. aesthetics, mechanics,
physics, sound design, etc.)
Resources
I’ve made numerous games of this type over the years, see the variations tag on my
website. I can make draft texts from my in-progress book available as needed.
Expected Outcome
I would like prototypes and accompanying design reflections that demonstrate user
experience designs for the software described above. These prototypes could be non-
interactive (e.g. video prototypes, screenshot mockups) or lightly interactive (e.g. FIGMA,
slideshow)
